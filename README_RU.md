# Dreamer Studio 2.0

**Портативная программа для FlashForge Dreamer под Windows x64.**

Dreamer Studio объединяет установку и восстановление прошивок, профили Ultimaker Cura и печать через локальный Wi-Fi-мост. Установка Python не требуется.

> **Внимание:** приложение предназначено для FlashForge Dreamer. Неподходящая прошивка или отключение питания во время записи могут повредить работу принтера. Убедитесь в совместимости и сохраните возможность восстановления.

## Возможности

- Установка модифицированной Marlin 2.0.9.7 с русским интерфейсом и меню Wi-Fi.
- Восстановление оригинальной V2.15, предыдущих образов и сборка настроенной штатной прошивки.
- Автоматическая установка конфигурации для Cura 5.13.
- Описание обоих экструдеров и исходный профиль для ABS на левом сопле T1.
- Локальный мост Cura → Wi-Fi-модуль Dreamer без облачных сервисов.
- Передача G-code на SD-карту FAT32 с проверкой целостности.
- Экспорт встроенных прошивок, профилей, исходников Marlin и документации.

## Требования

- Принтер **FlashForge Dreamer**.
- Windows x64.
- Совместимый драйвер USB-загрузчика Dreamer для прошивки.
- Ultimaker Cura 5.13 для автоматического добавления профиля.
- Работающий Wi-Fi принтера и SD-карта FAT32 для сетевой печати.

Cura и драйверы USB в EXE не включены.

## Быстрый запуск

1. После публикации релиза скачайте `DreamerStudio.exe` из раздела [Releases](../../releases).
2. Подключите один Dreamer по USB, закройте FlashPrint и другие программы, использующие соединение.
3. При необходимости выберите «Установить Marlin». Следуйте подсказкам по перезапуску; **не отключайте питание во время записи**.
4. Установите и один раз запустите Cura 5.13, затем закройте её. В Dreamer Studio нажмите «Установить профиль Cura».
5. Настройте Wi-Fi на дисплее принтера и узнайте его IP-адрес.
6. Введите IP в Studio, нажмите «Запустить мост» и «Проверить Wi-Fi».
7. Вставьте SD-карту FAT32. В Cura выберите Dreamer и «Print over network».

Полное руководство: [Инструкция Dreamer Studio](docs/Dreamer-Studio-Manual-RU.html).

## Wi-Fi и Cura

Cura обращается к `127.0.0.1:18899`, а локальный мост подключается к `<IP принтера>:8899`. Облако не используется. Файл сохраняется на SD как `/PIHCURA.GCO`, проверяется и только после этого запускается. После перезагрузки компьютера мост запускается снова.

**Важно:** предоставленный стартовый G-code рассчитан на **левый T1**. Правый T0 описан, но для печати справа и двумя соплами нужны отдельные настройки, калибровка и тестирование.

## Состояние проверок

На одном реальном Dreamer проверены установка Marlin, USB, Wi-Fi, SD и диагностическая передача с проверкой CRC. Диагностический файл завершился без нагрева и движения. **Полноценная печать детали после последнего обновления Marlin пока не проверена.** Не все версии оборудования и чистые установки Windows тестировались.

## Файлы программы и исходники

**Сейчас данный комплект содержит только документацию и файлы оформления GitHub.** Перед выпуском релиза нужно отдельно добавить `DreamerStudio.exe`, а для соответствующего распространения прошивок — исходники и лицензионные файлы.

Основой Marlin служит [moonglow/FlashForge_Marlin](https://github.com/moonglow/FlashForge_Marlin), Marlin 2.0.9.7. При распространении бинарной прошивки должны соблюдаться условия GPL-3.0, включая предоставление соответствующего исходного кода. Другие компоненты требуют отдельной проверки лицензий: [LICENSES.md](LICENSES.md).
