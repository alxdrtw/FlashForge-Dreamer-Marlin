Dreamer Studio 2.0
Всё для твоего принтера

Один переносной EXE: установка Marlin и штатной прошивки, профили Cura, локальный Wi-Fi-мост, резервные образы и эта инструкция. Python не требуется. Приложение не устанавливает Cura и USB-драйверы.

1. Первый запуск на другом ПК

  1. Скопируй DreamerStudio.exe в постоянную папку с правом чтения и запусти. Права администратора обычно не нужны. Программа рассчитана на Windows x64.
  2. Для USB-прошивки нужен доступный драйвер USB-загрузчика Dreamer. Кнопка «Проверить USB» проверяет обычную прошивку или Marlin. Если доступа нет, смотри раздел ошибок; драйверы автоматически не заменяются.
  3. Для автоматической установки профиля нужна установленная и хотя бы раз запущенная Cura 5.13. Закрой её перед нажатием «Установить профиль Cura». Установщик Cura в EXE не включён. Другие версии могут потребовать ручного импорта.
  4. Нажми «Открыть полную инструкцию» — она работает без интернета. «Экспортировать весь комплект» сохраняет прошивки, профили, проект куба, исходники Marlin и справку в выбранную папку.

2. Установить Marlin

Если на принтере уже стоит последняя сборка из этого комплекта, повторная установка не нужна: можно сразу настроить Cura и мост.

  1. Подключи один FlashForge Dreamer по USB. Заверши печать и выключи нагреватели. Закрой FlashPrint и программы, использующие USB.
  2. На вкладке «Marlin · Cura · Wi-Fi» нажми «Установить Marlin». Прочитай описание и подтверди замену прошивки.
  3. После начала ожидания выключи принтер на 5 секунд и включи, не отсоединяя USB. Приложение ждёт загрузчик до 3 минут. «Отменить ожидание» действует до начала записи.
  4. Во время передачи не отключай питание. Приложение проверяет контрольную сумму и только после подтверждения активирует установку. Дождись главного меню. Обычно принтер перезапускается сам; если загрузчик просит перезапуск, выполни его вручную.
  5. Нажми «Проверить USB». В ответе должно быть Marlin и FF_CURA_API:1 MODE:HTTP. Проверь меню «Конфигурация → Wi-Fi / Сеть» на дисплее.
Устанавливается готовая сборка: русский интерфейс, меню Wi-Fi, цель сопел до 270 °C, окно ожидания температуры ±5 °C, сохранение удержания Z при простое, Linear Advance с K=0. Коэффициент Linear Advance надо калибровать отдельно. Галочки и диапазоны на вкладке штатной прошивки не изменяют Marlin. Надпись v1.4 отдельного загрузчика не заменяется.

3. Настроить Cura

  1. Запусти Cura 5.13 один раз, затем полностью закрой.
  2. В Studio нажми «Установить профиль Cura». Будут добавлены описание Dreamer, оба экструдера, настройки ABS LEFT и адрес локального моста. Прежние заменяемые файлы сохраняются в %APPDATA%\cura\5.13\backups\DreamerStudio-2.0-…. Другие принтеры и настройки аккаунта не удаляются.
  3. Запусти Wi-Fi-мост в Studio, потом открой Cura. Выбери Dreamer @pih_a.
  4. Оставь активным LEFT T1 — ABS. Правое сопло в профиле присутствует, но отключено, потому что в проверенной конфигурации материал загружен только слева.

В ABS LEFT Tuned сохранены настройки после первого куба: компенсация первого слоя −0,15 мм, минимальное время слоя 10 с, внешняя стенка 20 мм/с, внутренние 35 мм/с, верх/низ 30 мм/с. Это исходная настройка для дальнейшей калибровки, а не универсальный профиль для любого ABS.

Правое сопло и двухцветная печать

Оба экструдера уже описаны. В Cura включи RIGHT T0, назначь модели нужное сопло и подбери материал. Текущий стартовый и завершающий код рассчитаны на T1 и выключают T0. Одного включения T0 недостаточно для печати справа или двумя соплами: нужны соответствующий стартовый код, обе температуры и настройка смены инструмента. Проверенный профиль двухсопельной печати в комплект не заявлен.

Смещение левого сопла уже настроено в прошивке. Не включай повторное применение смещений экструдера в Cura и не добавляй его ещё раз. Начни с тестовой модели, если меняешь сопла или прошивку.

Ручной перенос

«Экспортировать весь комплект» выдаёт папку Cura-install с файлами, которые надо скопировать в пользовательскую папку Cura 5.13 при закрытой программе, сохраняя подкаталоги. Удобнее использовать автоматическую установку Studio. Файлы .curaprofile можно импортировать через Preferences → Profiles → Import после добавления описания Dreamer. Проект Dreamer_ABS_LEFT_TUNED.3mf открывай как проект с его настройками; сетевое соединение при необходимости настрой кнопкой Studio.

4. Подключить Wi-Fi

  1. На дисплее принтера открой «Конфигурация → Wi-Fi / Сеть».
  2. Для домашней сети выбери «Через роутер», введи SSID и пароль, нажми «Подключить». Клавиатура: латиница, регистр и символы меняются кнопкой Aa/#. SSID — до 32 байт, пароль — 8–63; запятая запрещена протоколом модуля. Для открытой сети явно включи «Без пароля».
  3. Подожди подключения и нажми «Обновить IP». Если сразу после включения отображается 0.0.0.0, DHCP ещё не успел выдать адрес; обнови IP позже. Для стабильного адреса можно закрепить его на роутере.
  4. В Studio введи этот IPv4-адрес; значение 192.168.88.222 — адрес принтера, на котором проводилась отладка, на другом устройстве он может отличаться.
  5. Нажми «Запустить мост», через несколько секунд — «Проверить Wi-Fi». Мост должен получить настоящий ответ Marlin. Теперь открой Cura.

Режим «Точка доступа» создаёт сеть принтера. Подключи к ней ПК и используй IP, который показан на дисплее; не вводи автоматически адрес домашней сети. Изменение сети доступно только без печати, движения и нагрева. Пароль скрыт и хранится штатным Wi-Fi-модулем, не копируется в журналы Studio.

Мост необходим из-за штатного USR-C322: его ответы рассылаются всем TCP-клиентам, а Cura делает несколько запросов одновременно. Studio упорядочивает их. Cura обращается к 127.0.0.1:18899, мост — к IP принтера:8899. Плагин Cura не нужен. Мост принимает соединения только с этого ПК; облако не используется.

Мост работает в отдельном фоновом процессе того же EXE. Закрытие окна Studio его не останавливает. Для остановки используй «Остановить мост»; при незавершённой передаче остановка отклоняется. Для смены IP сначала останови мост, затем введи новый адрес и запусти снова. После перезагрузки ПК запусти мост заново. Сеть принтера при этом менять не надо. Прежний DreamerCuraWiFi.exe не должен одновременно занимать порт 18899.

5. Печатать из Cura

  1. Вставь внешнюю SD-карту FAT32 в Dreamer. Не извлекай её во время передачи и печати. Закрой FlashPrint и другие сетевые клиенты.
  2. Запусти мост и проверь Wi-Fi. В Cura выбери Dreamer и активное T1, открой модель, проверь материал и нарежь.
  3. Нажми Print over network. Передача ограничена примерно 6 КиБ/с: 1 МиБ занимает около 3 минут. Во время передачи Cura получает последний успешно прочитанный статус; свежий статус возвращается после загрузки.
  4. Принтер принимает файл полностью, сверяет CRC32, сохраняет на SD как /PIHCURA.GCO и только затем начинает выполнение. Следующая загрузка заменяет этот служебный файл; остальные файлы не удаляются. Без карты, при занятом принтере или неверной сумме запуск отклоняется.
  5. После полной передачи принтер печатает с карты. ПК и мост нужны для управления и статуса, но не для подачи следующих строк файла.

Поддерживаются обычные .gcode/.gco, не ZIP/UFP и не сжатые файлы; максимум 64 МиБ. Сетевое устройство добавлено как Dreamer, не выбирай профиль Ultimaker. Превью модели по сетевому API не реализовано; предупреждение об отсутствии preview_image не означает отказ загрузки G-code.

Стартовый код одновременно задаёт нагрев стола и левого сопла, ждёт температуры и выполняет Home после нагрева. Затем начинается таймер печати. Это устраняет прежнюю ситуацию с опусканием стола во время длительного нагрева. Завершающий код выключает нагрев, опускает стол на 40 мм в пределах программных ограничений, паркует X/Y и сохраняет удержание Z. После перезапуска координаты считаются неизвестными до Home.

6. Штатная прошивка V2.15

Вкладка «Штатная прошивка» — отдельный сборщик: русский язык, одновременный нагрев, отсчёт с первой экструзии, минимальные и максимальные значения ввода температуры. Значение 0 всегда выключает нагрев; диапазоны меню не заменяют аварийные пороги датчиков.

«Сохранить .BIN» только собирает файл, не трогая принтер. «Профиль ↓/↑» сохраняет и загружает JSON настроек сборщика. «Стартовый G-code» создаёт блок для штатного протокола Dreamer: не используй его в Marlin. Установка использует то же ожидание USB-загрузчика после ручного перезапуска.

Штатная экспериментальная компенсация подачи A — отдельный механизм, не Marlin Linear Advance. По умолчанию выключена и не заявляется как проверенная настройка печати. Готовый профиль native-270-ru-parallel-timer.json включён в экспорт.

7. Возврат и типичные ошибки

СитуацияЧто делать
Хочу вернуть прежнюю штатную RU 270«Вернуть штатную RU 270» на основной вкладке. Используется известный прежний образ.
Хочу заводскую V2.15«Вернуть оригинал» — без русского перевода и со штатными пределами. После замены Marlin используй FlashPrint и штатный протокол, а не этот Cura API.
Нужен предыдущий рабочий Marlin с raw TCPОбраз ROLLBACK_MARLIN_WORKING.bin включён в экспорт. В нём нет нового HTTP API и меню Wi-Fi. Не выбирай его как основной образ для новой сетевой печати.
USB не найден / Access deniedПроверь кабель с передачей данных, питание, один подключённый Dreamer, закрытые FlashPrint/другие загрузчики. USB CDC Marlin и фирменный загрузчик — разные устройства. На другом ПК может потребоваться совместимый драйвер для загрузчика VID 0315/PID 0001. Studio не меняет системные драйверы; если нужен драйвер, выясни его по устройству, не заменяй драйверы посторонних USB-устройств.
Нет ответа M601Нажми установку ещё раз и перезапусти принтер в течение окна ожидания. Вход может требовать нескольких попыток M601 — это делает программа. Не запускай два загрузчика одновременно.
Не подтверждена CRC/MD5 при прошивкеУстановка не активируется без подтверждения. Сохрани журнал, проверь соединение и состояние экрана. Не выдавай частично переданный файл за установленный.
Cura не видит принтерУстановлен ли именно Marlin из этого комплекта? Есть ли мост и правильный IP? HTTP-режим включён? FlashPrint закрыт? «Проверить Wi-Fi» должен дать реальный ответ. Мост не превращает штатную V2.15 или старый raw Marlin в Cura-устройство.
Порт 18899 занятЗакрой старый DreamerCuraWiFi.exe или второй мост. Studio не завершает произвольные процессы. Свой мост можно остановить кнопкой.
Нет SD-карты / SD write failedКарта должна определяться принтером и быть FAT32, с доступным местом и без повреждений файловой системы. Studio не форматирует карту. По USB M21 проверяет монтирование, M20 выводит список. Команды можно передавать внешним терминалом, если он совместим с Marlin CDC.
После обновления IP равен 0.0.0.0Дождись подключения и нажми «Обновить IP». Сохраняется адрес, прочитанный при загрузке; сам TCP-канал уже может работать.
Ось давит в упорОстанови движение и проверь концевик, проводку и механическую помеху. На этом принтере прежняя проблема Y была вызвана грязью. Повторными Home это не исправляется.

Журналы и настройки Studio: %LOCALAPPDATA%\DreamerStudio. Пароли Wi-Fi не запрашиваются на ПК и не сохраняются в журнале. Закрытие окна во время установки блокируется до завершения операции.

8. Состав и пределы проверки

  • Готовый Marlin: SHA-256 b25d2a4a3a41e2d63992d1713bafa41b3625393495065dffbaf4a98d5ea9eef8. Встроенные ресурсы проверяются по контрольным суммам перед экспортом/использованием.
  • Известная штатная RU 270, предыдущий рабочий Marlin, оригинальная V2.15 и сборщик штатных настроек.
  • Описание обоих сопел Cura, ABS LEFT Tuned, исходный FlashPrint Standard, его исходный INI, проект и STL куба 10 мм, JSON профиля штатной прошивки.
  • Исходники Marlin и лицензия GPL-3.0 в экспортируемом комплекте. База: moonglow/FlashForge_Marlin, Marlin 2.0.9.7. Приложение сообщает версию API 7.0.3 только для совместимости с сетевым клиентом Cura; реальная версия прошивки остаётся 2.0.9.7.

На реальном Dreamer подтверждены загрузка Marlin, USB, штатный UART6 Wi-Fi, монтирование SD, открытие Wi-Fi-меню, отказ при неверной CRC и успешная следующая загрузка диагностического файла 63 672 байта. Его выполнение завершилось без движения, экструзии и нагрева. Новая полная печать детали после последнего обновления не выполнялась. Смена SSID/пароля на реальном модуле не проверялась: текущая сеть была сохранена. На другом аппаратном варианте Wi-Fi SPI пока проверен только эмулятором.

Перепрошивка через протокол загрузчика проверена на этом ПК. Свежая Windows без драйверов и все аппаратные ревизии Dreamer не тестировались. Существующие тепловые защиты сопел и стола сохранены. Профиль предназначен для FlashForge Dreamer; другие модели им не прошиваются автоматически.
